### 小类观察

- **服装**:小类多是把较粗的中类再归一次,常用 `下装类 / 裙装 / 内搭类 / 外套类` 这类功能桶,或反向把 `短袖T恤→短T类`、`针织长裤→针织裤`、`梭织长裤→梭织裤` 收拢到更粗的桶。层级关系在 l2/l3 间存在反向现象(细→粗)。
- **鞋类**:小类多为品牌系列前缀(`MILANO板鞋`、`ORIGINALE老爹鞋`、`FITNESS跑步鞋`、`EXPLORE户外鞋`)或人群细分(`儿童跑鞋`、`儿童凉鞋`),本质是"系列/人群"维度而非更细品类。`儿童鞋` 这一中类下,小类几乎复刻了成人鞋的全套子品类(复古跑鞋 177、跑步鞋 108…)。
- **配件**:小类是具体形态——帽(棒球帽/圆帽/针织帽/空顶帽)、包(挎包/背包/双肩包/腰包)、袜(中腰袜/高腰袜/低腰袜)。

## 四、问题与建议

### 1. 中类同义/近义命名重复严重

不同来源的品类映射未归一,直接影响召回一致性、过滤准确率与统计口径。

| 应归一为 | 当前并存 | 合计 |
|---|---|---|
| 帽类 | `帽子`(433) / `帽类`(459) / `时装帽`(2) / `渔夫帽`(9) | ~903 |
| 包类 | `包`(529) / `包类`(369) / `配件`(3) / `配`(6) | ~907 |
| 袜类 | `袜子`(430) / `袜类`(109) | 539 |
| 跑鞋 | `跑鞋`(95) / `跑步鞋`(49) | 144 |
| 高尔夫鞋 | `高尔夫鞋`(38) / `高球鞋`(2) / `高尔夫球鞋`(2) | 42 |
| 户外鞋 | `户外鞋`(211) / `户外潮鞋`(3) | 214 |
| 板鞋 | `板鞋`(324) / `潮流板鞋`(2) | 326 |
| 帆布鞋 | `帆布鞋`(74) / `潮流帆布鞋`(3) | 77 |
| 内衣类 | `内裤`(8) / `平角裤`(8) / `内裤套装`(2) / `平角裤2件装`(2) / `配件内衣类`(5) / `一/二阶段文胸`(4+4) / `儿童成长文胸`(1) | ~34 |
| 短T | `短袖T恤`(1401) / `短T类`(511) | 1912 |

> 建议建一张 `category_l2_normalized` 映射表,把上述同义中类合并为一个标准值;统计与召回过滤都基于归一后的值。

### 2. l2/l3 语义层级错位

不少 l3 反而是比 l2 更"粗"的概念:

- `短袖T恤`(l2) → `短T类`(l3)
- `针织长裤`(l2) → `针织裤`(l3)
- `梭织长裤`(l2) → `梭织裤`(l3)
- `帽子`(l2) → `帽类`(l3)
- `短袖POLO`(l2) → `短T类`(l3)

做"按层级过滤/下钻"时不能假设 l3 比 l2 细,需先校验父子包含关系,否则会漏召回。

### 3. 服装中类颗粒度极不均

短袖T恤 1401 一枝独秀,而众多外套/裤装品类 < 30 条,长尾稀疏(棒球服 1、背带裙 1、毛呢上衣 2…)。做类目维度的推荐/搭配时,长尾类样本不足,需考虑合并到上级桶或与 `role`/`layer` 联合刻画。

### 4. 小类(l3)缺失率高且分布不均

- 整体 1,125 条(9.6%) l3 为空。
- 鞋类大部分中类无 l3(只有"系列前缀"或"儿童"细分时才填)。
- 依赖三级类目做召回存在盲区,建议在 l3 缺失时回退到 l2 + `role` + `layer`/`coverage`/`length_class` 等结构化字段补足。

### 5. 异常脏值

- `配件 > 包 > 小类=734`:1 条,疑似商品编码误入类目字段,应清洗。
- `配件 > 【赠品】FILA定制款户外小包`:1 条,赠品 SKU 是否进入推荐池需确认。
- `鞋类 > 中类=(空)` 2 条、`配件 > 中类=(空)` 10 条:中类缺失,应回溯上游品类映射。

## 附:生成方式

文档中的统计由以下脚本对 `data/processed/skus.jsonl` 直接计算得到(无需额外依赖):

```python
import json
from collections import Counter, defaultdict

l1=Counter(); l1l2=defaultdict(Counter); l2l3=defaultdict(Counter); total=0
with open('data/processed/skus.jsonl') as f:
    for line in f:
        line=line.strip()
        if not line: continue
        d=json.loads(line); total+=1
        a=d.get('category_l1','') or '(空)'
        b=d.get('category_l2','') or '(空)'
        c=d.get('category_l3','') or '(空)'
        l1[a]+=1; l1l2[a][b]+=1; l2l3[(a,b)][c]+=1
```
