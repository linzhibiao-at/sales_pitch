# FILA穿搭推荐系统资源需求清单

## 业务背景

FILA 官网系统中，用户可通过文字描述或发送商品图片，获取穿搭推荐服务。系统基于用户意图解析，结合固定搭配召回、向量语义拼套、ES 属性检索等多路召回策略，通过LLM 排序打分，生成个性化搭配推荐结果，并支持虚拟试穿功能。

---
