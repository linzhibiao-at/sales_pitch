## 数据质量观察

1. **大小写 / 空格不一致** — 同一逻辑系列被拆成多份：
   - `WHITE LINE`(745) / `WHITELINE`(3) / `white line`(2)
   - `PERFORMANCE`(700) / `performance`(1)
   - `MODERN HERITAGE` / `MODERNHERITAGE`
   - 联名系列大小写分裂：`FILA X Mr Doodle` ↔ `FILA X MR.DOODLE`、`FILA X moonge` ↔ `FILA X MOONGE`、`FILA X Kolor Beacon` ↔ `FILA X KOLOR BEACON`
   - `×` 与 `X` 混用：series `FILA × MAISON MIHARA YASUHIRO` ↔ sub `FILA X MAISON MIHARA YASUHIRO`

2. **series 与 sub_series 命名重叠** — 大量 series 下子系列只是把系列名复读一遍（`GOLF→GOLF`、`TENNIS→TENNIS`、`EXPLORE→EXPLORE`、`URBAN TECH→URBAN TECH`、`HERITAGE-FHT→HERITAGE-FHT` 等），而另一些 series 才是真正的层级关系（`PERFORMANCE→TENNIS/EXPLORE/TRAINING`、`ATHLETICS→FITNESS/GOLF/TENNIS`）。两套粒度没有统一约定。

3. **空 series 的 721 条**全部 sub_series 也为空，是同一批无标注数据，不是只缺一端。

4. **`FILA ORIGINALE` 作为 sub_series 高达 1247 条**，分散在 `ORIGINALE`(477)、`FILA ORIGINALE`(607)、`WHITE LINE`(81)、`LIFESTYLE`(82) 等多个 series 下——是被复用最多的子系列标签。

5. **联名系列（FILA X / FILA ×）长尾严重**：series 中联名类约占 20 余项，数量多在 1–43 之间，且大小写/分隔符写法不统一，建议归一化后再统计。

> 相关：[[series-pairing-rule]] 系列(series)同系-only 搭配规则；归一化前直接用于同系 pairing 会大面积漏召回。
