# FILA 穿搭推荐系统资源清单

## 业务背景

FILA 官网系统中，用户可通过文字描述或发送商品图片，获取穿搭推荐服务。系统基于用户意图解析，结合固定搭配召回、向量语义拼套、ES 属性检索等多路召回策略，通过规则/LLM 排序打分，生成个性化搭配推荐结果，并支持虚拟试穿功能。

## 技术迭代

FILA 官网系统增加 AI 穿搭推荐功能，采用 FastAPI 单进程架构，集成多模态大模型（意图解析、视觉理解、排序打分、推荐理由生成）、向量数据库（图文/文本向量检索）、Elasticsearch（商品属性检索与搭配索引）、Embedding 服务（图文向量生成），提供 SSE 流式对话推荐体验。

| 环境 | 容器数量 | 规格 | 用途 |

| 生产环境 | 2 个容器 | 4 Core 16 GiB | FastAPI 推荐服务（含前端静态资源） |

### 2. 阿里云 Elasticsearch 集群

生产环境和测试环境都需要。

| 配置项 | 说明 |
|--------|------|
| ES 版本 | 7.9.3 |
| 索引数量 | 2 个（SKU 单品索引 `fila-skus`、搭配索引 `fila-outfits`） |
| 数据规模 | SKU 商品属性 + 搜索文本 + 图片 URL；固定搭配组合 |

**节点配置（建议）**

| 节点类型 | 规格 | 节点数量 |
|----------|------|----------|
| 数据节点 | 2 核 4 GiB | 2 |
| 协调节点 | 2 核 4 GiB | 1 |

| 资源类型 | 说明 |
|----------|------|
| 内网服务打通 | FastAPI 服务 ↔ ES 集群、Milvus 实例、LLM Gateway、Embedding 服务 |

| 负载均衡 | 生产环境 2 容器负载均衡 |

### 5. 外部服务依赖（已有，无需额外申请）

| 服务 | 用途 | 调用方式 |
|------|------|----------|
| LLM Gateway | 意图解析、视觉理解、排序打分、推荐理由生成 | OpenAI Compatible API |

| Hive 商品表 | 日更商品数据拉取 | JDBC / CSV 下载 |

## 环境变量清单

| 变量 | 用途 |
|------|------|
| `ANTA_LLM_API_KEY` | LLM 调用密钥 |
| `ARK_API_KEY` | Embedding 服务密钥 |
| `ES_HOSTS` / `ES_USERNAME` / `ES_PASSWORD` | ES 集群连接与认证 |
| `FILA_MILVUS_MODE` | Milvus 模式（local / cloud） |
| `FILA_MILVUS_URI` / `FILA_MILVUS_TOKEN` | Milvus 连接 |
| `FILA_MILVUS_USERNAME` / `FILA_MILVUS_PASSWORD` | Milvus 云端认证 |
| `HIVE_USERNAME` / `HIVE_PASSWORD` | Hive 数据源认证 |
