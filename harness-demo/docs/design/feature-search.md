# 搜索功能设计

## 目标

搜索功能为项目、任务、用户等核心资源提供统一查询能力，支持关键词、状态、时间范围和分页排序。

## 范围

包含：

- 基础关键词搜索。
- 多条件过滤。
- 分页。
- 排序。
- 查询结果权限过滤。

不包含：

- 独立搜索引擎接入。
- 跨库全文检索。
- 实时推荐。

## 分层设计

- domain: 搜索条件、排序字段、资源类型枚举。
- mapper: MyBatis SQL 查询和分页。
- service: 查询条件规整、权限过滤、结果组装。
- controller: 接收查询参数并返回分页结果。

## 数据库约束

搜索 SQL 必须兼容 MySQL 5.7。需要关注索引命中，避免无边界的全表扫描。

## API 约定

搜索接口应使用 `GET` 或 `POST`。简单查询使用 `GET`，复杂查询条件使用 `POST`。

分页参数：

- `pageNum`: 页码，从 1 开始。
- `pageSize`: 每页数量。
- `sortBy`: 排序字段白名单。
- `sortOrder`: `asc` 或 `desc`。

## 测试要求

- 关键词为空。
- 多条件组合。
- 分页边界。
- 非法排序字段。
- 权限过滤后的结果。
