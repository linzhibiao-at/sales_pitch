# 认证授权设计

## 目标

认证授权模块负责用户登录态识别、权限校验和访问控制，为 controller 和 service 提供统一的安全上下文。

## 范围

包含：

- 登录认证。
- 当前用户上下文。
- 接口访问权限校验。
- 角色和权限点关联。
- 登录失败和无权限错误处理。

不包含：

- 用户资料管理。
- 组织架构维护。
- 第三方单点登录，除非有明确业务需求。

## 分层设计

- domain: 用户身份、角色、权限点枚举。
- config: 认证过滤器、拦截器、安全上下文 Bean。
- mapper: 用户、角色、权限数据查询。
- service: 登录、权限判断、上下文加载。
- controller: 登录接口、登出接口、当前用户接口。

## 关键规则

- 认证组件必须通过 Spring 注入，不允许手动 `new`。
- 未登录返回 `AUTH_401`。
- 无权限返回 `AUTH_403`。
- 密码、token 等敏感信息禁止写入日志。

## 测试要求

- 登录成功。
- 登录失败。
- 未登录访问受保护接口。
- 无权限访问接口。
- token 过期或无效。
